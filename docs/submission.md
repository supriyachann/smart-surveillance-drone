## Problem statement

Manual patrols and fixed CCTV can leave coverage gaps across large campuses and disaster-affected areas. Operators may receive delayed information and need significant time to inspect remote locations. The project explores mobile aerial monitoring and timely detection alerts to support authorized human review while reducing unnecessary exposure of personnel.

## Solution description — software prototype

A local monitoring prototype provides a dashboard for inspecting person/vehicle events, reviewing alerts and exporting results. It includes synthetic playback and an optional YOLO adapter for authorized video or webcam input. A Pixhawk/Raspberry Pi drone integration is designed but not flight-tested. Actual inference, accuracy, latency and flight time still require validation. Synthetic samples are explicitly labeled.
